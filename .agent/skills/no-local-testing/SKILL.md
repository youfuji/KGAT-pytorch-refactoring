# ローカルテスト禁止

## ルール

- **テスト・モデル実行はすべてGoogle Colabで行う**。ローカル環境では実行しない
- スモークテストスクリプト（`test_*.py`）のローカル実行を提案しない
- トレーニングスクリプト（`main_*.py`）のローカル実行を提案しない
- 勾配フロー可視化スクリプト（`visualize_*.py`）のローカル実行を提案しない
- 検証計画（Verification Plan）にローカル実行ステップを含めない

## やるべきこと

- コード変更のみをローカルで行う
- 検証はユーザーがColabで手動実施する前提で計画する
- 検証方法を聞かれた場合は「Colabでの実行手順」を案内する
